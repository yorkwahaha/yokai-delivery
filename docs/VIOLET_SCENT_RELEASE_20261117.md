## 玩家可見調整

- 第七招顯示為 **紫藤毒香（しとうどっこう）**，類別為「粉紫毒霧」；不再顯示「墨跡・步痕」。為兼容既有存檔，內部鍵仍為 `ink_trail`。
- Lv1～Lv4 隨移動沿路散發毒霧，毒傷按 0.5 秒結算，離開煙霧還會中毒；Lv5「覺醒・迷魂藤香」對一般敵人短暫混亂 2.5 秒，可能轉頭攻擊同伴。Boss 只受毒傷、不受混亂。
- 四變異保留舊內部 ID，玩家看到的名稱改為「紫藤・霧華擴散」「紫藤・毒香入骨」「紫藤・長夜留香」「紫藤・餘香纏身」，分別增加毒霧半徑 25%、每秒毒傷 25%、地面留香 1.8 秒、離開毒霧後的毒傷 1.6 秒（Lv5 混亂再增加 0.5 秒）。
- 第八招「距爆・封印釘」仍依玩家離位距離自動引爆、不新增操作鍵；Lv5 兩段破封。
