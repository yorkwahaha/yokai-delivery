每輪執行的三條規則

1. 有畫面或有功能

每一工作包必須讓一關更接近完成，產出可玩版本、可審素材或修復可重現問題。

2. 完成才改狀態

單一素材核准≠整關；加速測試≠自然實玩；Chrome尺寸≠實體iPad效能。

3. 不撞檔、不瞎忙

各 Agent 主＋副工作獨立。遇人審則切另一條線，沒真 Bug 就不硬改，不擅部署。
