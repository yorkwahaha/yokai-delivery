取捨、跨 Agent 衝突、S8 發行前整合。美術／玩法／部署最終決策屬使用者。

不可違反的兩行約束

  1. 不按通關直接加 meta 戰力、破壞平衡。圖鑑收藏與通關進度不得提供戰力加成；數值成長只來自單局內構築，違者回滾。
  2. 圖片特效原則：正式畫面只用真實手繪圖。粒子、光影、VFX 僅為輔助；禁止以程式幾何、色塊或未核准候選冒充正式美術，缺圖就留空或 fallback，不得偷渡。

每輪執行的三條規則

1. 有畫面或有功能

每階段必須讓一關更接近完成：可玩版本、可審素材或修復可重現問題。

2. 完成才改狀態

單一素材核准≠整關；加速測試≠自然實玩；Chrome 尺寸≠實體裝置效能。

3. 不撞檔、不瞎忙

各 Agent 獨立檔區。遇人審切另一條線，沒真 Bug 不硬改，不擅部署。
