## 核心目標與禁止混淆

1. 「變異」＝原武器仍在、不吃武器槽，改變攻擊方式並提供清楚的實際收益。玩家自願選取，維持已實作的低出率（符合資格約25%、顯示後至少隔3級、每次最多一張）；不再把雞肋分傷視為升級。
2. 「合技（共鳴合武）」＝**指定兩項主動武器都 Lv5**＋取得「共鳴繪馬」才可啟動。玩家在融合面板明確確認後，兩把母武器**從實際攻擊迴圈和主動欄位消失**，換成**一把新合武**，淨釋出一個主動欄位；它不是目前 Lv3 雙技能的 15～20% 額外被動。
3. 融合後新武器獨立技能 ID、攻擊時序、命中/追蹤、音效/VFX、冷卻、傷害、成長/圖鑑條目；不准只改原招顏色、名稱或重複播放兩招。合技視作完成覺醒的武器，初版不再要求額外升等。
4. 預設每局**最多一次合技**（未來是否開第2次需先有十分快局體感與效能證據）。目標讓玩家約在 **6～8 分鐘**有機會取得並使用，而不是到結算畫面才發生；此時間是可驗證的目標，不是聲稱已做到。
5. 保護目前第二關 Normal 平衡基準：XP 需求80%、普通怪3 XP、吸取180px、普通怪Hard HP/速度/生成、Boss300/650/900/1400、遠程只保低HP shiome。Stage1、真Hard快照、既有運送/卡片/日語題目、2D/2.5D、所有音效資產不能因合技發生回退。

## 既有程式約束（真實已查）

- js/game.js 有 WI 基礎技能、WL 1～5級、MAX_ACTIVE_WEAPONS=4、MUTATION_CONFIG 與 DUO_CONFIG（duo_inkfire/duo_thundercircle/duo_frostseal/duo_cinderseal），以及 buildDuos；目前 duo 在 Lv3+ 只是附加傷害/控場，**不能誤當成完成的合技**。
- js/config.js 有 AWAKEN_EVERY=3、AWAKEN_MAX=4，Lv4→Lv5需消耗1枚覺醒印記，兩母技Lv5需要兩枚。先真測十分快局能否在6～8分達標，若不足，提交量測與最小修正提案；不要擅自修改第一關或全域印記門檻。
- 左下摺扇主動槽位、選卡/圖鑑、手把/平板操作與 diegetic/classic HUD 需一起支持新武器ID與釋出槽位；不准出現「角色看似融合，原攻擊仍暗中發射」的雙重增傷。
- 舊DUO_CONFIG用於保留回歸與遷移；合技成立時同組舊雙技被動不能再觸發或二度加傷。歷史測試中Stage1/Lv3 combo仍保留原樣，除非後續明確改動經審核。

## 共鳴繪馬觸發機制（P1 原型契約）

1. 初步觸發：第二關，時間達約6:00、玩家持有一對符合條件的Lv5母武器，擊倒該時段之後的Boss或精英時掉落一次共鳴繪馬；若事件先於滿級到來，須有**可追蹤的待領資格／補發規則**，避免任務已完成卻永遠不掉。Codex可選擇符合現有事件hook的最小可實作版本，不另外創建龐大的掉落系統。
2. 不准因本關路線很長、6次配送才能拿兩枚印記而導致合技無法在6～8分鐘成形。以實際配送/覺醒印記/升級收入測可達性；若6～8分門檻難以完成，先附錄測量，再提出針對第二關的最小修正方案；不要私改全關設定。
3. 拾取繪馬時進入暫停的專用二擇確認畫面：顯示兩個來源技能、融合後結果、將釋出1格，並可**選擇稍後融合/取消**；不得強迫融合、不可消耗但卡住。手把與觸控應可確認/取消。
4. 狀態轉移必須**原子性**：來源兩招Lv5仍在時才可交易；交易成功一次扣除兩來源、裝入新武器並釋出一格；拒絕/中途失敗不扣武器、不扣繪馬；pause/失敗/結算/restart 不重複授獎、舊投射物與異步特效不掛住。
5. 母武器已有變異時**不可悄悄浪費玩家的選擇**：P1原型先紀錄完整來源變異，在融合面板標出如何承接。由 Codex 最少量決策為『特定變異相容並以合技內有限加成承接』或『明確補償一次免費非變異強化選擇』之一；禁止把所有原派生與變異疊起來造成無上限傷害。未驗證相容前不默默吞掉投入。
