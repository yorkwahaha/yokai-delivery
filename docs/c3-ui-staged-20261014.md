## 檔案

- `js/card-gallery-ui.js`
- `tests/card-gallery-ui.test.cjs`

呼叫端把已經 `project` 好的卡片、篩選和頁碼傳進來，並傳入現成的 `drawRibbonSlices`、`drawWoodTag`、`drawButton`、`readableFont`。有 `button_secondary.webp` 的 naturalWidth 時，八張牌用這張真圖當紙札。沒有這張圖就只畫字，不畫牌面主體。

0–3 印只畫「鎖」和 `n/4`。滿 4 印畫日文、中文、假名，並明確寫 `4/4`。不畫詞性、例句、羅馬字、emoji，也不把內部 key 印出來。篩選鈕文字是「關卡：全部／指定」和「詞包：全部／指定」。紙面是淺色和紙，字色固定深墨 `#24180f`，並帶 `maxWidth`。

可點的鈕（篩選、翻頁、返回、再聽）高寬至少是 `44 / viewport.scale` 個邏輯像素，也就是至少 44 CSS 像素。相鄰不重疊，落在 `VIEWPORT.calculate` 的可見範圍裡。卡面可以比這個小。很矮的畫面會減少欄數或每頁張數，而不是畫出界。

跨關的同一張卡在兩個關卡篩選裡都是同一個物件。換篩選會把頁碼拉回 0。超出的頁碼會夾回最後一頁。返回的結果是 `close: "pause"`。再聽鈕是 disabled，理由 `audio-frozen`，模組裡沒有 AUDIO 或 TTS。
