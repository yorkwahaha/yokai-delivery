## 3. 雨港熄燈根因

Phase B 的 seed 117 首王破封 200.55、擊殺 450.80，二王破封 493.00、擊殺 560.95。最終在 625.90 熄燈，580 秒段之後仍有三筆送達，最後一筆在 617.40 剩 30.64 油。舊控制器在油高於 65 時可能離開配送追王，未為潮扇、漩渦專門找安全點，也未走一般戰鬥的天氣推進。這筆證據支持「王戰與路線耦合」，不足以把單局歸因於 Boss HP 或 +35 獎勵。

Phase C 原值的 seed 117 熟練與一般策略首王破封約 181 秒，當時仍有 98.47／99.91 油，至約 212／211 秒熄燈，王還剩 248.38／277.04 HP。破封後同時受傷 85.04／87.16 油，純耗油約 13.75／13.05。防禦與低效率策略在部分種子甚至未遇首王便熄燈。這些死亡無法由擊殺獎勵解決。seed 482 與 931 的熟練、一般策略都可四王通關，同場高低差顯示構築與走位支配曝險。

雨港兩王 HP 300／650、移速 98，夜行町 150／325、58。Phase B 同 Build 受控讀數為雨港每分鐘約 12–13 招、夜行町約 10 招。在本輪自然策略，雨港單次送達路徑中位 1,651 px，比夜行町約長 18%。交戰會轉移配送目標並增加在小怪、潮扇及雙王區域的時間，失去回油與成長的節奏。這是受控比較及自然輸入證據的共同方向，仍欠真人路徑與閃避採樣。

額外三 seed 傷害歸因顯示，117 熟練整局實扣 105.04，其中普通鬼與跑者 87.04、潮扇 18。117 一般整局 147.16，Boss 接觸 10，其餘是普通鬼、跑者與坦克。相反，482 一般通關仍吃了潮扇 54、漩渦 16、Boss 接觸 40，且透過路線和多筆補油維持戰鬥。油耗包括來自小怪的累積傷害，雨港的挑戰不能只讀王戰面板或單看 HP。Phase D 應先看實際轉角受擊、跑單被截斷和雨港安全線視認，再判斷是否需要另試首王後搖。

## 12. Phase D 優先順序與真人驗收

本機預覽已確認 HTTP 200。從旅路正常進關，未解鎖時可用本機關卡實驗入口。 [本機試玩](http://127.0.0.1:8788/?dev=1&stageLab=1)

1. **雨港 Normal。** 用防禦或低輸出 Build 打前兩王。記錄破封前後、擊殺後與下一單送達時的油量，順便標記潮扇、轉角或小怪哪一個造成路線中斷。Phase D 優先檢查潮線、海妖與配送導引的視認。
2. **竹影迷宮。** 用平常的 Build 打首王再跑一次終王。觀察連續竹筍、切線、窄道轉身，以及百鬼時是否仍看得見合法出口。Phase D 優先處理這些預警與障礙辨識。
3. **夜行町。** 開局錯一單後照常玩，記下一單的等待時間、能否順利接回節奏，以及提示是否讓人知道怎麼補救。
4. **妖櫻山道。** 自行判讀題目與路線直到終王，觀察櫻根／風刃與配送提示是否互擋，回旅路確認清關和竹影入口。若手上已有靈針 Lv5，順手觀察橫移王約 390 px 的有效命中。
5. **iPad Safari 與實體手把。** 優先在雨港或竹林確認長玩時背景、亮燈及高壓畫面，並試一次手把選卡、答題和結算返回。Phase D 的音效排序先補櫻天狗、竹林王預警及影響揮刀、射擊確認的缺槽。
