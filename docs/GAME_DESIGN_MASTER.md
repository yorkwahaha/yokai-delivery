# 妖怪快遞社｜現行遊戲設計總綱

更新：2026-11-27；此版取代舊版「兩關先行、十融合、委託九格」開發順序，舊企劃完整封存。未核准候選不是正式規則。

## 核心體驗
- 玩家扮演妖怪夜町快遞員，以移動、衝刺與自動妖術保護燈油，配送日文單字、回答詞義、解除 Boss 封印，透過短局重玩與技能組合練習 N5 詞彙。字卡收藏不等同通過 JLPT。
- 標準局約 10 分鐘，正常鍵盤 WASD＋空白衝刺；觸控點擊選取，手把 A 選取／Y 重抽。2D／2.5D 可切換，正式 tilt=.60。實際 Boss、配送、反噬、冷卻、血量與回油以 `js/game.js`、Boss state machine 及現行回歸為準。
- 反噬為麻痺／停火，錯答不直接扣燈油；封印讀題提供安全時段。場上前王不阻擋其他排定波次，尾王擊殺才結算勝利。不可因整合或文件整理擅自調平衡。

## 技能與成長
- 基礎六招：妖刀、靈陣、狐火、陰陽符、天狐雷、靈針。妖刀起手，四個主動槽（非第五槽），正常 Lv1–5；每招四變異、每局至多兩種，不重複。
- 第 7–9 招（第一關起開放）：紫藤毒香（ink_trail）、封印釘（seal_nail）、白狼式神（shikigami）。現行 V2.1 數值與變異見 LATE_SKILL_MUTATIONS_20261121.md；舊墨爆、離位引爆、紙幟已淘汰。
- 第 10–13 招：破魔・神弓、絡新婦・妖絲、冰魄・妖毬、冥風・風穴；第一關起全部開放，公開試玩；本機隔離 Skill Lab 仍可測。詳細數值見 ACTIVE_SKILLS_10_13_DESIGN.md。
- 十三招共用既有等級權重與三選一卡池，未持有 Lv0 技能同權重，無通關專屬介紹、保底或新技能優先；四槽、Lv5、變異、關卡解鎖維持。
- 融合暫停；既有程式及圖保留，不啟用。正式平衡與四槽限制維持。DEV guided draft 與前四關錯峰為 A/B 候選，不等同正式改版。
