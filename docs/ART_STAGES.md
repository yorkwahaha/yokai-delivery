# Yokai Delivery｜第一季八關美術需求表（版本 B）

版本 1.0｜2026-10-21｜依 `docs/ART_STYLE.md` 統一美術；Prompt 可直接搭配 `docs/ART_PROMPTS.md` A1–A6。**需求 ≠ 實際已生圖、USER_APPROVED 或上線。**

## 共通交付量與品質
每關至少有：G 主材與副材（各一類）、T 材質過渡、D 少量透明地表貼花、H 辨識建築、O 場景小物、L 關卡地標（可歸 H/O）、E/B 專屬怪物與王（**目前暫緩美術量產**）。類別是需求，不代表每關數量須完全一致。
新候選統一進 `art/s1/`…`art/s8/`，文件和 manifest 放同級；舊 `art/stageN-.../` 一律不搬。所有 G **正上方平面材質**，所有 H/O **淺 3/4 單物件**，怪物微Q。每次生成前獨立核預算、reference SHA、用戶當次是否核准。

## Stage 1｜夜行町 `night-town` — `art/s1/`
- **主／副地板（G）**：青灰夜雨石板 + 緊實巷道泥地；低對比、少量暖黃燈籠映色，避免整格亮斑。建議 `g_stone_01.png`、`g_dirt_01.png`。
- **過渡／貼花（T/D）**：石→泥不規則邊、零星積水與落葉。候選 `t_stone_dirt_h01.png`、`d_water_01.png`。
- **建築（H）**：町屋商店／酒館／小神社；比照目前已核准現役房屋 **不擅自替換**。候選新增樣式 `h_shop_01.png`。
- **物件與地標（O）**：鳥居、路牌、石燈、和風町街標識。禁角色通行路線被密集房屋擋死。
- **敵人／王（E/B）**：現役小怪與大妖鬼照現有行為先保留；若做新關專屬版本需另審輪廓。
- **一行題材 Prompt**：「夜色日式町屋巷道，石板與微濕泥地，溫暖燈影但整面均勻；地材從正上方畫，房屋獨立 3/4，和紙水墨浮世繪」。

## Stage 2｜雨夜港町 `rain-port` — `art/s2/`
- **G**：深藍灰不規則**扁平板石**（**不是圓卵石**）＋潮濕舊木棧道；中性俯視，不可直接拿舊 stone_v3 自帶斜視角整張鋪。候選 `g_stone_01.png`、`g_wood_01.png`。
- **T/D**：石→木兩個世界方向的自然接縫、稀疏積水反光、少量苔痕；避免大亮斑週期；`t_stone_wood_h01.png`、`t_stone_wood_v01.png`、`d_water_01.png`。
- **H**：碼頭倉庫、魚鋪、酒館、商店、茶屋，**屋頂尺度一致**；避免一棟重複排成街。先保留已做的 Nano 候選與現役，不自動核准。
- **O/L**：木桶、魚箱、錨、繫纜柱、漁船、岸邊照明；**不使用與漁港不符的石燈籠**，不要在海面生成陸地道具。
- **環境構圖**：左右長距離延伸；**下方海面／碼頭、上方山壁或港町建物**，雨向陸海一致，石木接合自然。
- **E/B**：少量低血量遠程怪（只有一種）、港町專屬 Boss 攻擊不要只是第一關套皮；怪物美術暫緩。
- **一行題材 Prompt**：「雨夜漁港，海風吹濕的藍灰扁平石板與舊木碼頭，手繪墨線／積水低反差；G 用無透視的正上方表面，H/O 用統一淺斜角獨立透明」。

## Stage 3｜妖櫻山道 `sakura-pass` — `art/s3/`
- **G**：暖褐不規則山道泥地＋灰綠神社參道石階／板石；花瓣少量散落，低對比、大筆觸，杜絕每格重複花團。候選 `g_dirt_01.png`、`g_steps_01.png`。
- **T/D**：泥→石階、零星花瓣與苔。 `t_dirt_steps_h01.png`、`d_petal_01.png`。
- **H**：小型神社、茶亭、山屋；現有神樂殿／古櫻及三地面**已核准部分保留**，以前退件的大巨石庭院／錯透視神社候選不得復活。
- **O/L**：古櫻、鳥居、細小岩塊、步道繩與牌；**建築數量減半到三分之一密度**以免像難民營。
- **E/B**：櫻妖／天狗候選只作待審；主題需有唯一攻擊視覺。
- **一行題材 Prompt**：「櫻花山道的低反差泥地與灰綠石階，墨刷暈染與少量花瓣；不可變成大石頭鋪滿、規則棋盤或浮誇粉紅海報」。

## 製作順序／驗收
1. 先 **S2 單張全新「近俯視石板」母圖**做透視和石形審核：用原 stone_v3 **只作 style reference**，不是誤旋轉／幾何變形原斜圖。不要新一輪連續多張付費試錯；先預算 Gate。
2. 單張被人審接受後才 offline 無縫 → 變體 → 3×3 / 6×6 / 10×10；次序不倒轉。初輪不搶目前三位系統 Agent 的 js writer。
3. 然後 S2 木道、石木過渡、透明建築／物件跟進，按人審逐批；其它關共用同製法但各關獨立場景識別。
4. **怪物最後**，不自動復活之前拒收稿；使用者 A/B 選畫師、人審、runtime、發布都是**不同 Gate**。
