### 日文出題模擬

`node tools/measure-first-four-phase-a.cjs quiz` 對基準和現版各跑 20 詞 × 64 seeds × 4 關。字系規則在 2+1 分組時從多數二選一，其餘三猜。審查原表對「答案已知不在多數組」的樣本也計三猜，因此 S1 原估約 48.4%，按可執行猜法重算為 45.85%。其餘三關相同。

| 關卡 | 只靠字系猜中 | 同詞無序干擾組碰撞／40,320 對 | 同詞相鄰組重複／1,260 對 |
| --- | ---: | ---: | ---: |
| 夜行町 | 45.85% → **33.33%** | 211 → 186 | 4 → 0 |
| 雨夜港町 | 50.00% → **33.33%** | 354 → 242 | 10 → 0 |
| 妖櫻山道 | 50.00% → **33.33%** | 1,620 → 470 | 53 → 0 |
| 竹影迷宮 | 48.33% → **33.33%** | 2,137 → 1,315 | 64 → 0 |

現版 5,120／5,120 題有三個不同且有詞義的選項。字系、字長及三種標記的有無在同題一致。正解位置各關介於 31.02–35.16%，同詞至少觀察到 6 組干擾對。選項仍用正常日文拼寫，包含既有混寫；日語流暢度、語義是否太近、及更複雜的字形記憶策略仍需真人驗證。這個結果量測的是選項重複，出題詞本身的複習頻率仍由原詞庫和配送排程控制。
