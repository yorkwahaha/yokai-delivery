# Yokai Delivery — 旅路地圖可視化編輯器

## 一鍵啟動（Windows）

雙擊專案根目錄的 **`開啟旅路地圖編輯器.cmd`**，會啟動 Node.js 本機服務並嘗試自動打開瀏覽器。

如果瀏覽器沒有自動打開，手動在同一台電腦開啟：

`http://127.0.0.1:8766/editor/overworld.html`

也可以在專案根目錄執行 `node tools/map-editor-server.cjs --open`。完成後在終端機按 **Ctrl+C** 關閉編輯器。

## 編輯位置

1. 左側選 **夜行町／雨夜港町／妖櫻山道／竹影迷宮…**，也可以選 **路口**（9 個過渡節點）。
2. 上方選 **道路**、**地標**、**木牌** 三種工具，然後直接在地圖上拖曳。
   - **道路**＝關卡實際行走停靠與道路線段端點，影響角色站位／可點圓點。
   - **地標**＝關卡立體屋／櫻花／鳥居等裝飾的位置，不影響道路；可用左側比例滑桿調整大小。
   - **木牌**＝關卡名稱的牌子，不影響角色和地標；可調整木牌寬度。
3. **背景** 模式可拖曳整張風景圖，左側背景寬度滑桿可調整 35%–115%，100% 表示寬度 3000 世界單位；原圖為 1672×941 像素，縮小不會產生新的高解析細節。
4. 滾輪只調整**編輯器畫布檢視倍率**，不影響玩家遊戲的背景大小。空白鍵＋拖曳或中鍵拖曳可移動畫布，**顯示完整地圖**恢復全圖。
5. **裝置安全框** 可查看桌面 900×600、橫式手機 1298×600、直式手機 900×1948／900×2000、平板 900×629 的相對可視範圍。這是編輯輔助框，不是新的關卡。
6. **復原／重做**（Ctrl+Z / Ctrl+Y），**備份 JSON／匯入 JSON**，以及刷新後可手動**恢復上次瀏覽器暫存**。

## 儲存與正式遊戲

完成後點右上角 **「套用至本機遊戲」**。

本機服務會驗證 17 個 ID、位置及尺寸資料，並直接寫入 `js/overworld-layout.js`。**正式遊戲 `index.html` 已經載入此檔，因此重新整理本機遊戲頁即可套用你調整的道路、地標、名牌與背景位置**；不需要再把 JSON 貼給 AI，也不需要修改硬編碼座標。

**這不是 Git Commit 或正式部署。** 編輯器只綁定 127.0.0.1，不能由網路上的學生打開。編輯器的 JSON 備份適合存成不同構圖方案。

## 保護現有玩法

- `js/overworld.js` 仍保留原先的 17 個節點及 16 條道路 ID；**只能編輯位置／大小，不能刪除、創造關卡或改解鎖邏輯**。
- 前兩關已實作內容仍可進入，第三至第八關依 `js/words.js` 繼續封印。
- 原本 `yokai-delivery-v1` 存檔、言靈圖鑑進度等資料不變。
- 背景縮小後，南側仍會使用同一張圖的鏡像與霧化補景，不會額外下載圖片。

## 工具與驗證

- `js/overworld-layout.js`：正式使用的獨立位置設定表。
- `editor/overworld.html` ＋ `editor/overworld-editor.js`：專用互動編輯器。
- `tools/map-editor-server.cjs`：本機 HTTP 服務及設定儲存 API。
- `tools/map-editor-smoke.cjs`：真實 Chrome 頁面操作與拖曳／儲存／讀回驗證。**測試會自動還原設定原檔，請不要在測試執行時同時編輯。**
- `tests/overworld-editor.test.cjs`：驗證道路、裝飾及木牌三層分離、背景位置套用。
- `artifacts/validation/map-editor-visual-smoke.png`：Chrome 截圖。

注意：若本機 8766 連接埠被其他服務占用，先關閉舊服務再啟動編輯器。
