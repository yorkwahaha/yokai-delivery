美術審核

截圖取自 Phase D 的實際 Canvas 定格，可點圖看大圖。重繪沿用半水墨、浮世繪、和紙印痕與強墨線，地面採正投影，角色和物件保留腳底錨點。

P1 · 竹影迷宮 · 切線與筍陣

重繪原因　靈陣亮邊與細長黃白切線容易混讀，連續五次的筍陣仰賴輪廓。

美術方向　切線用深墨與暖赭雙邊、塊面端點。筍陣五段使用一致形狀，中央留空。兩種視角下沿現有命中區。

交付規格　切線 768×144、筍陣 512×512，透明 PNG 原稿及 WebP。

P1 · 雨夜港町 · 潮扇與雨渦

重繪原因　白浪、青色靈陣及兩種預警疊在一起，扇緣與安全帶難以追蹤。

美術方向　預警用墨邊輪廓、中心留透明。水柱及白浪高亮留在命中層。兩種視角核對扇緣與三／五渦位置。

交付規格　潮扇和雨渦各 1024×1024，前搖、命中分層，透明 PNG／WebP。

P2 · 雨夜港町 · 港口海面

重繪原因　連鋪的白浪弧線重複，搶走岸邊預警對比。

美術方向　以四向可相鄰的四張變體調整浪峰位置和疏密，保留靛藍粗墨與紙面。先檢視 3×3、6×6 和 10×10 連鋪。

交付規格　四張 512×512，不透明正投影 WebP。

P2 · 竹影迷宮 · 竹叢與路口

重繪原因　同向高竹的剪影近似，茶屋旁窄路的轉向出口不易定位。

美術方向　竹叢用兩種疏密、低明度葉面與暖色竹節，靠通路一側留隙，維持現有碰撞和根部錨點。

交付規格　竹柱 384×1024、竹叢 640×768，透明 PNG／WebP。

P2 · 竹影迷宮 · 草帽妖突進

重繪原因　土褐帽緣與走道、筍妖接近，群戰難辨待機與攻擊。

美術方向　用帽沿傾角、手部剪影和淺米內襯區分姿勢，少量冷色布襯，兩格同腳底與朝向。

交付規格　待機／攻擊各 512×512 RGBA。

P2 · 妖櫻山道 · 王招姿勢與羽刃

重繪原因　姿勢切換跳接，櫻粉環境削弱羽刃方向。定格用來比背景對比，姿勢銜接需連續觀看。

美術方向　夜櫻鬼姬做蓄勢、發招、收勢，原地對腳。羽刃保留扇形和櫻紋，尖端深墨與短暖邊標方向。

交付規格　角色三格各 512×512 RGBA。羽刃 768×320 透明 PNG／WebP。

P3 · 妖櫻／竹影 · 紫藤毒香與封印釘技能卡

重繪原因　縮圖能分色，紫藤與封印釘主體仍容易只被認為是光渦或爆光。

美術方向　紫藤用沿腳步拉長的低伏紫煙。封印釘用大墨釘及清楚落點。留出現有卡框裁切和名稱區。

交付規格　每張中心圖 820×1230，不透明 WebP，無字無框。
