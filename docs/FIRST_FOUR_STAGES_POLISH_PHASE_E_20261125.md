1. **正常旅路。** 從遊戲首頁點「旅路地圖」。新進度可進夜行町，後三關依 DEV 通關紀錄解鎖。
2. **直接選關。** 總覽有四個預選連結。進遊戲後點「開發選關」→「直接進關」。也可直接用雨港或竹影連結。 [PC 雨港](http://127.0.0.1:8002/?dev=1&s3play=1&perf=1&phase=E-f54e755&stage=rain-port) · [PC 竹影](http://127.0.0.1:8002/?dev=1&s3play=1&perf=1&phase=E-f54e755&stage=bamboo-maze) · [iPad 雨港](http://192.168.50.107:8002/?dev=1&s3play=1&perf=1&phase=E-f54e755&stage=rain-port) · [iPad 竹影](http://192.168.50.107:8002/?dev=1&s3play=1&perf=1&phase=E-f54e755&stage=bamboo-maze)
3. **隔離與版號。** 頁首顯示 Phase D 基準與 Phase E 載入版，遊戲網址含 `phase=E-f54e755`。寄送與通關使用 `yokai-delivery-dev-v1`，卡冊用既有 DEV 卡冊鍵。Phase E 將旅路上次停留、教學讀寫分入 DEV 專用鍵，首次使用可能從旅路起點開始並再看到教學。正式同來源記錄保留，公共站與本機各有瀏覽器來源。
4. **效能 JSON。** 進關後開「效能實驗」，長局留在「H 實玩與長期採樣」，抽樣繪圖指令關閉，維持完整效果及解析度。需留存病徵時直接點「下載診斷 JSON」。每關長局及 512 靈玉各留一份，檔名加裝置／關卡／情境。

PC 鍵盤預設 WASD 或方向鍵移動、空白鍵衝刺、E 取貨、P 或 Esc 暫停、V 切視角。iPad 使用畫面虛擬搖桿、衝刺鈕和視角鈕。

**8002 診斷。** 開始時無 8002 listener。現以專案的 `tools/serve-tilt.cjs` 分別監聽 `127.0.0.1:8002` 和實體乙太網路 `192.168.50.107:8002`。Windows 從兩個地址取得 HTTP 200，測得音訊 Range 回 206，進關及下載也已在 Windows Chromium 用兩個網址核對。iPad 到 PC 的跨裝置連線仍待本人開頁確認。防火牆與全域安全設定維持原設定。 [Apple Safari 媒體伺服器說明](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/CreatingVideoforSafarioniPhone/CreatingVideoforSafarioniPhone.html)

## 2. 真人實機驗收表

建議先用 iPad 跑雨港及竹影，途中同時記錄下表的平衡與裝置項。另用 PC 補一次雨港失單和一個不同的竹影構築。每局記裝置、輸入、視角、技能及等級、遊戲鐘和剩油，遇到問題留截圖或 JSON。

| 項目 | 操作 | 觀察 | 通過標準 |
