# 動作與旅路素材

本次採「百鬼繪卷」：沿用既有墨線與和風手繪造型，用身體姿態表達狀態，旅路通關用開窗、亮燈與朱印呈現。另曾比較夜行版畫（克制輪廓）、提燈劇場（燈火引導）與影繪百鬼（剪影紙影）；沒有改造整套 UI 或戰鬥場景。

| 素材 | 格式／用途 |
|---|---|
| `ghost/runner/boss/mis/tank/shooter_motion_v1` | 每張兩格：第二移動幀、攻擊瞬間；第一移動幀保留原圖 |
| `player_dash_v1` | 衝刺前傾、踏出後腿、提燈與背箱完整 |
| `player_win_v1` | 結算舉燈、站定、微笑 |
| `player_kneel_v1` | 結算跪地疲憊，提燈未破損；未製作另一張倒地圖 |
| `map_night_town_v1` | 夜行町，暗窗／開窗暖燈兩格 |
| `map_rain_port_v1` | 雨夜港，雨濕倉屋／碼頭／船，通關暖燈兩格 |

1. 原稿為 PNG，遊戲使用 quality=90、alphaQuality=100 的 WebP，失敗可退回 PNG。未修改既有原始角色／敵人圖，未縮放原稿；11張PNG約14.80MiB、WebP合計2566692bytes（約2.45MiB）。用既有 bundled sharp 做格式編碼，沒有安裝新依賴或更改全域環境。
2. 圖像由內建 `image_gen` 依專案素材參考生成，未使用 CLI／API key。完整最終提示與參考檔為 `artifacts/validation/art-generation-prompts.json`。最初角色三格稿的配件跨格，因此改用三張獨立圖；未採用稿不在正式素材目錄。
3. 輪廓與材質契約：保留狐耳、深藍浪紋羽織、木背箱與紙提燈；敵人保留原形與武器；地標以屋簷／碼頭大輪廓辨識。禁止新加霓虹外框、整片光霧或不明文字。朱印「済」由Canvas畫字，不由生成圖片負責。
4. 三項形狀規則：角色保持完整剪影、攻擊武器清楚伸展、地標有可辨識屋簷／港口底座。三項禁止：配件跨相鄰圖格、姿態以翻轉或亮度變化假扮新幀、用光效遮住輪廓。成功用舉燈／開窗，失敗用跪地／垂肩；狀態不只靠顏色。
5. 配色與材料沿用原作：深藍衣料、朱紅繩結／朱印、暖金紙燈、舊木與灰瓦。標題與按鈕繼續用既有字體與UI色票，不新增任意設計token。展示順序是角色／敵人動作，再勝敗結算，再地圖；不把素材試演按鈕加到正式遊戲。
6. 動作以每秒6次兩幀切換；碰撞受傷／護盾抵擋或射出敵彈時顯示0.24秒攻擊幀。沒有修改傷害、碰撞半徑、攻擊冷卻或提前攻擊判定。停頓／暫停沿用既有遊戲時間流程；這不是多幀骨架動畫。
7. `renderer.js` 的 `FRAME_BOUNDS` 是讀取Alpha邊界後的來源矩形／水平錨點，`drawFrame` 以共同腳底位置繪製，攻擊格沿用第二移動格的縮放。命中白剪影按圖片＋格索引快取。更新圖片時需更新矩形，勿只換檔案；`tools/inspect-art-frames.py` 只讀圖像並輸出資料，不改像素。
8. 減少動態時停用敵人步伐切換、角色步伐／衝刺殘影、旅路浮動與選取脈動；仍以靜態衝刺／攻擊姿態表達正在發生的操作。沒有宣稱全遊戲完全無動畫。
9. 旅路只替換目前兩個可玩關卡的地標。亮燈／朱印依 `STORE.isStageCompleted`；紀錄依該關bestScore，不創造新星級評分。角色站在地標旁，沿路顯示位移平滑銜接；不改關卡節點、道路鄰接或觸控命中位置。
10. 驗收：PNG／WebP尺寸一致、Alpha逐像素相同；來源裁切不超出圖片；勝敗圖不蓋住結算資訊；手機568×320／桌面900×600可辨識，缺圖可退回舊素材。資料與圖片在 `artifacts/validation/art-*`。原稿較高解析，尚無手機載入時間、常駐記憶體或實機FPS證據。

素材編碼可使用 `node tools/encode-art-assets.cjs <bundled-sharp-module-path>`；讀取邊界使用帶 Pillow 的專案／bundled Python 執行 `tools/inspect-art-frames.py`。
